# SHARP — Build Guide

Описан процесс локальной сборки проекта от клонирования до запуска `sharp --help`. Всё, что выходит за эти рамки, считается out of scope.

---

## 1. Пререквизиты

На этом локальном компьютере:

| Инструмент | Версия | Статус |
|------------|--------|--------|
| **Python** | 3.10.5 | ✅ установлен |
| **pip** | 26.2.1 | ✅ установлен |
| **git** | 2.39.1 | ✅ установлен |
| **conda** | — | ❌ не установлен |
| **uv** | — | ❌ не установлен |

Файл `.python-version` указывает на Python 3.13, но проект будет собираться с текущим Python 3.10.

> **Примечание**: `venv` доступен через `python -m venv`.

---

## 2. Сборка

### Шаг 1. Клонировать репозиторий

```bash
git clone https://github.com/apple/ml-sharp.git
cd ml-sharp
```

### Шаг 2. Создать виртуальное окружение

```bash
python -m venv .venv
.venv\Scripts\activate
```

### Шаг 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### Шаг 4. Установить пакет

```bash
pip install -e .
```

### Шаг 5. Проверить установку

```bash
sharp --help
```

## 3. Open Questions

### 3.1. Версия Python: 3.10 vs 3.13

Файл `.python-version` и `pyproject.toml` (`pythonVersion = "3.13"`, `target-version = "py39"`) указывают на Python 3.13 как целевую версию. Однако на этом компьютере установлен Python 3.10.5.

**Блокирует задачу**: возможно. Зависит от совместимости зависимостей (`torch`, `gsplat`, `timm`) с Python 3.10. Если `requirements.txt` содержит зависимости, не поддерживающие Python 3.10, шаг 3 (`pip install -r requirements.txt`) может завершиться ошибкой. Требуется проверка при выполнении.
